# Postcard

Postcard is a desktop app that plans and produces social media content for you: it drafts a few weeks of posts, writes each one, makes the images and video, and waits for your approval before anything goes out. Download the build for your computer from the [latest release](https://github.com/quvi-ai/postcard/releases/latest) — Windows (`.exe` installer), macOS (`.dmg`), or Linux (`.deb` or `.AppImage`) — and open it; from then on Postcard tells you when a new version is ready and installs it once you say yes.

This repository holds the downloadable builds only.
