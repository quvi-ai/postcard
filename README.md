# Postcard

Postcard is a desktop app that plans and produces social media content for you: it drafts a few weeks of posts, writes each one, makes the images and video, and waits for your approval before anything goes out. Download the build for your computer from the [latest release](https://github.com/quvi-ai/postcard/releases/latest) — Windows (`.exe` installer), macOS (`.dmg`), or Linux (`.deb` or `.AppImage`) — and open it. Every installer includes source-built GPL FFmpeg; the matching release includes its corresponding source and license notices in `ffmpeg-gpl-source.tar.gz`. Windows, macOS, and Linux AppImage installs can apply updates in place after you approve them; Debian `.deb` installs link to the matching package for manual installation.

All platform installers include the source-built GPL FFmpeg runtime and ffprobe; the matching
release also provides the corresponding source and license notices in `ffmpeg-gpl-source.tar.gz`.

This repository holds the downloadable builds only.
